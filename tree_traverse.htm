要在一棵樹上走訪(traverse)時，可以有很多種不同的方式，但主要的方式有以下四種：

  • 前序(pre-order)：先處理自己，再處理左子樹，再處理右子樹，即以「中左右」的順序處理。
  • 中序(in-order)：先處理左子樹，再處理自己，再處理右子樹，即以「左中右」的順序處理。
  • 後序(post-order)：先處理左子樹，再處理右子樹，再處理自己，即以「左右中」的順序處理。
  • 層序(level-order)：先處理深度 0 的節點，再處理深度 1 的節點，再處理深度 2 的節點，...，直到所有節點都被處理過。需要注意的是，一般來說，同層的節點會是左邊先處理。

其中，若你的樹是運算樹，則前、中、後序三種走訪的結果，就是前、中、後序三種運算式（但中序式的括號需要有另外的原則補上，此篇不做相關說明）。

以基礎介紹看過的這棵樹來說，

四種走訪的順序分別如下：

  • Pre-order: A B D E G H C F
  • In-order: D B G E H A C F
  • Post-order: D G H E B F C A
  • Level-order: A B C D E F G H

而在實作上，前、中、後序三種走訪會靠遞迴來實作，而層序則需要用 queue 來實作，如下：

class TreeNode(object):
	def __init__(self, val, left=None, right=None):
		self.val = val
		self.left = left
		self.right = right


def pre_order(root):
	if root:
		print(root.val, end=' ')
		pre_order(root.left)
		pre_order(root.right)


def in_order(root):
	if root:
		in_order(root.left)
		print(root.val, end=' ')
		in_order(root.right)


def post_order(root):
	if root:
		post_order(root.left)
		post_order(root.right)
		print(root.val, end=' ')


def level_order(root):
	q = [root]
	while q:
		node = q.pop(0)
		print(node.val, end=' ')
		if node.left:
			q.append(node.left)
		if node.right:
			q.append(node.right)


# Construct
root = TreeNode('A')
b = TreeNode('B')
c = TreeNode('C')
d = TreeNode('D')
e = TreeNode('E')
f = TreeNode('F')
g = TreeNode('G')
h = TreeNode('H')
root.left = b
root.right = c
b.left = d
b.right = e
e.left = g
e.right = h
c.right = f

pre_order(root)
print()

in_order(root)
print()

post_order(root)
print()

level_order(root)
print()

但若你是隨便寫下一組自以為的前序和中序走訪，則樹有可能不存在，例如前序走訪為 A B C D E，中序走訪為 C E A B D，則以 A 為 root 分割左右後，看中序走訪的左子樹應包含 C E，但這很明顯的不可能在前序走訪走出 B C，因此樹不存在。

事實上，前、中、後序三種走訪天生就跟遞迴和堆疊相對應。你可以把前序走訪當作進堆疊的順序，中序走訪當作出堆疊的順序；則若能經由堆疊操作讓這樣子的進出方式成立，樹就會存在，反之則不存在。
